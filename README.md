# TEAM BALANCE

밝은 캐릭터 기반 팀 워크숍 밸런스 게임. Next.js 15 / React 19 / Supabase / Vercel.

## 실행

```bash
npm install
npm run dev
```

현재 버전은 UI 및 진행 흐름 프로토타입입니다. Supabase 프로젝트에 초기 DB 스키마는 적용됐지만 실제 다중 기기 투표 API, 인증, 점수 트랜잭션은 아직 개발 중입니다. 실제 운영용으로 사용하지 마세요.

환경변수는 `.env.example`을 참고하여 로컬 `.env.local` 또는 Vercel 프로젝트 설정에만 저장하세요. 비밀키는 Git에 커밋하지 마세요.
